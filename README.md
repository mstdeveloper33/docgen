# docgen

A hybrid documentation generator for Dart and Kotlin projects. Extracts code structure via static analysis and generates rich Markdown docs locally or with Gemini AI.

## Features

- **Hybrid mode:** Generate docs locally (no API key) or use AI for rich output
- **Multi-provider AI:** Gemini, OpenAI, Claude, and Ollama (fully local LLM)
- **Dart AST analysis:** Class, constructor, and method extraction via `package:analyzer`
- **Kotlin support:** Regex-based parser for Kotlin file structures
- **Git-aware:** Only processes changed files, falls back to full project scan
- **Token-optimized:** Strips method bodies, sends only structural data to AI
- **Zero-config local mode:** Works without any API key

## Installation

### From pub.dev (recommended)

```bash
dart pub global activate docgen
```

### From GitHub

```bash
dart pub global activate --source git https://github.com/mstdeveloper/docgen.git
```

### Compile native binary

```bash
git clone https://github.com/mstdeveloper/docgen.git
cd docgen
dart pub get
dart compile exe bin/docgen.dart -o docgen
# Move binary to PATH
mv docgen /usr/local/bin/
```

## Usage

### Local mode (no AI required)

```bash
# Run in your project directory
docgen run
```

Analyzes all `.dart` and `.kt` files and generates markdown in the `docs/` folder.

### AI mode (multi-provider)

```bash
# First-time setup - select provider and enter API key
docgen init
# Prompts:
#   Select AI provider: 1) Gemini  2) OpenAI  3) Claude  4) Ollama
#   Enter API key (not needed for Ollama)
#   Model (optional override)

# Generate rich documentation with configured AI
docgen run --ai
```

Supported providers:

| Provider | API Key | Local | Models |
|----------|---------|-------|--------|
| **Gemini** | Required | No | gemini-2.0-flash, gemini-1.5-pro, ... |
| **OpenAI** | Required | No | gpt-4o-mini, gpt-4o, ... |
| **Claude** | Required | No | claude-sonnet-4-20250514, claude-3-haiku, ... |
| **Ollama** | Not needed | Yes | llama3, codellama, mistral, ... |

### Output example

After running `docgen run`, a markdown file is created for each class in `docs/`:

```
project/
├── lib/
│   └── src/
│       └── auth_repository.dart
└── docs/
    └── auth_repository.md    ← generated doc
```

Generated `auth_repository.md` content:

```markdown
# auth_repository

> Auto-generated by docgen

**Source:** `lib/src/auth_repository.dart`

## AuthRepository

### Constructors

\`\`\`dart
AuthRepository(String baseUrl, Duration timeout)
\`\`\`

### Methods

| Method | Parameters | Return Type |
|--------|-----------|-------------|
| `login` | `String` email, `String` password | `Future<Map<String, dynamic>>` |
| `logout` | — | `Future<void>` |
| `refreshToken` | `String` token | `Future<Map<String, dynamic>>` |

### Usage Example

\`\`\`dart
final authRepository = AuthRepository(
  baseUrl: '...',
  timeout: Duration(seconds: 30),
);

final result = await authRepository.login('...', '...');
await authRepository.logout();
\`\`\`
```

## How It Works

```
┌─────────────┐     ┌──────────────┐     ┌─────────────────┐     ┌──────────┐
│ Git Watcher │────▶│ AST Analysis │────▶│ Local / AI      │────▶│ docs/*.md │
│ (diff/scan) │     │ (Dart/Kotlin)│     │   Generator     │     │  output  │
└─────────────┘     └──────────────┘     └─────────────────┘     └──────────┘
```

1. **Git Watcher:** Detects changed files via `git status`, falls back to full directory scan
2. **Analyzer:** Extracts public structure via Dart AST or Kotlin regex parser (bodies stripped)
3. **Generator:** Produces markdown using local template or AI (Gemini/OpenAI/Claude/Ollama)
4. **Output:** Writes to the `docs/` folder

### 2. GitHub Releases (native binaries)

Compile platform-specific binaries and attach to a GitHub release.

#### Manual release:

```bash
# macOS (Apple Silicon)
dart compile exe bin/docgen.dart -o docgen-macos-arm64

# macOS (Intel)
dart compile exe bin/docgen.dart -o docgen-macos-x64

# Linux
dart compile exe bin/docgen.dart -o docgen-linux-x64

# Windows (cross-compile or build on Windows)
dart compile exe bin/docgen.dart -o docgen-windows-x64.exe
```

#### GitHub Actions CI/CD (automated):

Create `.github/workflows/release.yml`:

```yaml
name: Release Binaries

on:
  push:
    tags: ['v*']

jobs:
  build:
    strategy:
      matrix:
        include:
          - os: ubuntu-latest
            artifact: docgen-linux-x64
          - os: macos-latest
            artifact: docgen-macos-arm64
          - os: windows-latest
            artifact: docgen-windows-x64.exe
    runs-on: ${{ matrix.os }}
    steps:
      - uses: actions/checkout@v4
      - uses: dart-lang/setup-dart@v1
      - run: dart pub get
      - run: dart compile exe bin/docgen.dart -o ${{ matrix.artifact }}
      - uses: softprops/action-gh-release@v2
        with:
          files: ${{ matrix.artifact }}
```

Users install with:
```bash
# Download from releases page
curl -L -o docgen https://github.com/mstdeveloper/docgen/releases/latest/download/docgen-macos-arm64
chmod +x docgen
mv docgen /usr/local/bin/
```

### 3. Homebrew Tap (macOS)

Create a separate repo `homebrew-tap`, then add a formula:

```ruby
# Formula/docgen.rb
class Docgen < Formula
  desc "AI-powered documentation generator for Dart and Kotlin projects"
  homepage "https://github.com/mstdeveloper/docgen"
  url "https://github.com/mstdeveloper/docgen/releases/download/v1.0.0/docgen-macos-arm64"
  sha256 "REPLACE_WITH_SHA256"
  license "MIT"

  def install
    bin.install "docgen-macos-arm64" => "docgen"
  end
end
```

Users install with:
```bash
brew tap mstdeveloper/tap
brew install docgen
```

## Configuration File

`.docgen.json` (created by `docgen init`, auto-protected with `chmod 600`):

```json
{
  "provider": "ollama",
  "apiKey": "",
  "baseUrl": "http://localhost:11434/v1",
  "model": "codellama"
}
```

| Field | Required | Description |
|-------|----------|-------------|
| `provider` | Yes | `gemini`, `openai`, `claude`, or `ollama` |
| `apiKey` | For cloud providers | Your API key |
| `baseUrl` | No | Custom endpoint (defaults per provider) |
| `model` | No | Override default model |

> Add `.docgen.json` to your `.gitignore` — it contains your API key.
